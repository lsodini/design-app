# Design Portfolio

An interactive design portfolio exploring 9 iconic design movements: Brutalism, Minimalism, Futurism, Bauhaus, Art Deco, Memphis, Art Nouveau, Constructivism, and De Stijl.

## Tech Stack

- React 19
- React Router v7
- Framer Motion
- Bootstrap 5

## Getting Started

```bash
npm install
npm start
```

## Deploy on Vercel

The project includes a `vercel.json` with SPA rewrite rules. Just connect your repository to Vercel and it will deploy automatically.
